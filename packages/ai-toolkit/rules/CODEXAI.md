## How to use available skills

- Use `/build-traceability-matrix` when you want to map requirements to BDD scenarios, architecture artifacts, and implementation evidence.
- Use `/code-review` when you want to review code changes, check a PR, or get feedback on code quality based on team engineering conventions.
- Use `/detect-documentation-drift` when you want to compare architecture documentation with the current implementation and find mismatches.
- Use `/extract-behaviors-from-bdd` when you want to derive runtime behaviors or coverage from Gherkin feature files.
- Use `/generate-adr` when you want to draft or update an Architecture Decision Record.
- Use `/generate-arc42-documentation` when you want to produce or refresh arc42 architecture documentation from repository evidence.
- Use `/generate-c4-model` when you want to infer a C4 system model from the codebase and supporting docs.
- Use `/generate-plantuml-diagrams` when you want to create or update PlantUML architecture diagrams.
